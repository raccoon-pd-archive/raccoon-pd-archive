# Raccoon Police Department — Incident Archive

> Internal records, S.T.A.R.S. unit, July 1998.
> Maintained by Capt. E. Marini.

This repository preserves the dispatch logs, radio transcripts, and field
notes recovered from the events of July 23–25, 1998 — the period now
referred to internally as the **Mansion Incident**.

The records are kept here for use by S.T.A.R.S. command and the City
Manager's office. They are not for public release.

## Index

- `transcripts/` — verbatim radio chatter, time-stamped to UTC-5 (Raccoon).
- `Notes.md` — Capt. Marini's running observations during and after the
  Bravo deployment.
- `incident-photos/` — operational photography (provided separately;
  contact dispatch for the file index).
